## Quick start (Terraform, AWS)

Creates one EC2 instance (default `t3.xlarge`, 60 GB gp3) in the default VPC that runs the Docker Compose stack. Secrets are generated by Terraform and kept in SSM Parameter Store. This creates billable resources.

1. Requirements: Terraform 1.5+, AWS credentials, a default VPC in the region, and the AWS CLI with the Session Manager plugin for shell access.
2. Get the files:
   ```bash
   git clone https://github.com/aisolutionscamp/stacks.git
   cd stacks/stacks/ai-agent-framework/terraform/aws
   ```
3. Deploy, allowing only your own IP:
   ```bash
   terraform init
   terraform apply \
     -var "allowed_cidr=$(curl -s https://checkip.amazonaws.com)/32" \
     -var "flowise_admin_email=you@example.com"
   ```
4. Wait about 10 minutes for the first boot (images and model download).
5. Get the owner password with the command from the `admin_password_command` output, then open `flowise_url` and log in.
6. Shell access without SSH: run the `ssm_session_command` output. The stack lives in `/opt/ai-agent-framework`.
7. The connection is plain HTTP. Add TLS (for example an ALB with an ACM certificate) before you use it for real data.
8. Remove everything: `terraform destroy` (same `-var` arguments).
